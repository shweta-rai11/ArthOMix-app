Screenshots go here.

Naming convention used by the chapter files' `knitr::include_graphics()` calls:
`f<chapter-number>-<n>.png`, e.g. `f20-1.png` is the first screenshot in
Chapter 20 (Quality Control). Each chapter's `_fig1`, `_fig2`, ... chunk
labels are numbered in the order they appear in the chapter.

Recommended: full-window screenshots, cropped to just the card/tab being
described, saved as PNG.
