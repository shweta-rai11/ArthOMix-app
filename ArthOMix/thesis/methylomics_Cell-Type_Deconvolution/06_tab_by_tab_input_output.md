# 06. Tab-by-Tab Input/Output Summary — Methylomics Cell-Type Deconvolution

## Table 1 — Tab summary

| Tab | Purpose | Input Data | Main Functions | Processing | Output | Next Connection |
|---|---|---|---|---|---|---|
| 1. Data & QC | Resolve a working beta-scale matrix and apply probe/sample QC filters | `methyl_dataset$beta` (shared) or a module-scoped CSV/TSV upload | `methyl_ct_detect_scale()`, `methyl_ct_pct_to_beta()`/`methyl_ct_m_to_beta()`, `methyl_filter_missing()`, `methyl_filter_sex_chr()`, `methyl_filter_snp()`, `methyl_filter_cross_reactive()`, `methyl_filter_detection_p()`, `methyl_fs_sample_missing_ok()`, `methyl_probe_retention_cascade()` | Scale-detect → optional explicit-click transform → sequential probe filters (each on the progressively shrunk matrix) → sample-missingness filter | `ct_filtered()$mat` (QC-filtered working matrix); QC retention cascade table (counts unreliable after step 1 — see `07`) | Feeds every later tab as the working matrix |
| 2. CpG Feature Selection | Rank and optionally restrict marker CpGs off the chosen reference's centroids | `active_reference()` (from Tab 3), optional custom CpG-list upload | `methyl_ct_marker_rank()`, `methyl_ct_select_markers()`, `methyl_ct_top_n_balanced()`, `methyl_ct_chr_allowed_ids()` | Rank every reference CpG by effect/specificity → filter by direction/specificity/chromosome scope/custom list → top-N cap balanced across cell types | `fs_result()$selected` (marker table); bar/heatmap/scatter figures | Optional — feeds `ct_active_markers()`, consumed by Tabs 3's overlap QC and Tab 4's deconvolution; skippable |
| 3. Reference & Method | Choose the reference matrix, estimation method, and advanced solver parameters; see the overlap-QC gate | `methyl_ct_reference_registry()` (7 built-in panels) or custom reference upload; `ct_filtered()$mat`; `ct_active_markers()` | `methyl_ct_reference_registry()`, `methyl_ct_get_reference()`, `methyl_ct_parse_custom_reference()`, `methyl_ct_overlap_qc()`, `methyl_ct_overlap_by_type()` | Resolve reference → optional cell-type subset → compute marker/working-matrix CpG-ID overlap % → gate Run button on overlap threshold | `active_reference()`; overlap-QC message/table; enabled/disabled Run button state | Feeds Tab 4's `decon_result()` |
| 4. Deconvolution | Estimate cell-type proportions | `ct_filtered()$mat`, `active_reference()`, `ct_active_markers()`, advanced parameters | `methyl_ct_run_epidish()` (→ `EpiDISH::epidish()`) or `methyl_ct_run_hepidish()` (→ `EpiDISH::hepidish()`) | Re-derive/re-validate marker-restricted reference → intersect CpG IDs with the working matrix → drop incomplete-case CpG rows → run CP/RPC/CBS/hepidish | `decon_result()$fractions` (samples × cell types); `results$celltype` summary | Feeds Tabs 5, 6, and Export |
| 5. Cell Composition | Visualize and statistically compare estimated fractions | `decon_result()$fractions`, `decon_result()$sheet` (optional phenotype) | `methyl_ct_plot_stacked_bar()`, `methyl_ct_plot_heatmap()`, `methyl_ct_plot_box()`, `methyl_ct_composition_pca()`/`_mds()`, `methyl_ct_plot_scores()`, `methyl_ct_plot_corr()`, `methyl_ct_group_stats()`, `methyl_ct_plot_group_diff()` | Direct visualization of the fraction matrix (no CpG-scale reuse); Wilcoxon/Kruskal-Wallis + BH-FDR against an uploaded grouping column | 5 figure panels + group-comparison table/plot | Feeds Export's "Phenotype-linked fractions" / "Group comparison results" downloads |
| 6. Validation | Sanity-check the deconvolution result | `decon_result()$ref_used`, `$working_mat`, `$fractions` (frozen at last Tab 4 run) | `methyl_ct_reconstruct()`, `methyl_ct_validation_metrics()`, `methyl_ct_compare_methods()`, `methyl_ct_method_correlation()`, `methyl_ct_method_agreement_summary()`, `methyl_ct_plot_bland_altman()` | Forward-simulate the mixture model and compare to observed data; rerun EpiDISH per selected method on the identical inputs and compare pairwise | Correlation/RMSE/MAE/R² cards + per-sample table; method-correlation heatmap + Bland-Altman + agreement table | Terminal — no further tab consumes this tab's output |
| 7. Export | Download every intermediate/final object | `ct_filtered()$mat`, `fs_result()$selected`, `decon_result()$ref_used`/`$fractions`, `cmp_result()$stats$table` | plain `utils::write.csv()`/`writeLines()` in 7 `downloadHandler`s | Serialize whichever steps have already run; each button gated by its own has-run flag | 6 CSV files + 1 text summary report | Terminal |

## Table 2 — Function summary

| Function | Package/File | Used In | Input | Operation | Output | Scientific Purpose |
|---|---|---|---|---|---|---|
| `methyl_ct_reference_registry()` | `celltype.R` | Tab 3 UI build, `ct_registry` | none | Lists 7 EpiDISH built-in reference panels, dimensions read live off the installed objects | list of specs | Enumerate available reference panels without hard-coding versions |

| `methyl_ct_unavailable_methods()` | `celltype.R` | Tab 3 UI | none | Static list of unimplemented methods + reasons | list | Backend-honesty disclosure |

| `methyl_ct_pct_to_beta()` / `methyl_ct_m_to_beta()` | `celltype.R` | transform handler, `ct_source()` | matrix | Deterministic scale conversion | matrix | Normalize to beta scale for downstream math |

| `methyl_ct_run_epidish()` | `celltype.R` (wraps `EpiDISH::epidish()`) | `decon_result()`, `methyl_ct_compare_methods()` | filtered beta matrix, reference, method/params | Overlap+completeness validation, then CP/RPC/CBS estimation | `list(ok, fractions, ...)` | Core single-stage deconvolution |
| `methyl_ct_run_hepidish()` | `celltype.R` (wraps `EpiDISH::hepidish()`) | `decon_result()` (hepidish branch) | as above + second-stage reference | Two-stage hierarchical estimation | `list(ok, fractions, ...)` | Deconvolution when a sub-type-resolving second reference is available |

| `methyl_ct_validation_metrics()` | `celltype.R` | `val_result()` | observed, reconstructed matrices | Correlation/RMSE/MAE/R², overall + per-sample | list | Quantify how well fractions explain observed data |

| `methyl_ct_method_correlation()` / `methyl_ct_method_agreement_summary()` | `celltype.R` | `cmpm_result` outputs | fractions-by-method list | Pairwise correlation / mean-abs-difference | matrix/data.frame | Quantify method agreement |
| `methyl_ct_group_stats()` | `celltype.R` | `cmp_result()` | fractions, group vector | Wilcoxon or Kruskal-Wallis + effect size + BH-FDR per cell type | list | Test composition differences between phenotype groups |
| `methyl_ct_composition_pca()` / `methyl_ct_composition_mds()` | `celltype.R` | `build_ord_plot()` | fraction matrix | `prcomp()`/`cmdscale()` directly on fractions | list(scores, ...) | Ordinate samples by composition similarity |
| 12 `methyl_ct_plot_*()` builders | `celltype.R` | throughout Tabs 2/5/6 | various result objects | `ggplot2` figure construction, `theme_arthomix()` styling | `ggplot` object | Visualization |
| `EpiDISH::epidish()` | EpiDISH (installed) | inside `methyl_ct_run_epidish()` | beta matrix, reference, method | Dispatches to `DoCP`/`DoRPC`/`DoCBS` | `list(estF, ...)` | Reference-based methylation deconvolution |

## Table 3 — Data flow (stage summary)

| Stage | Object | Data Type | Dimensions | Created By | Used By | Purpose |
|---|---|---|---|---|---|---|
| 1 | `src$mat` | numeric matrix, beta scale | CpG rows (data-dependent) × sample cols (data-dependent) | `ct_source()` | `ct_filtered()` | Common beta-scale input regardless of source path |
| 2 | `ct_filtered()$mat` | numeric matrix, beta scale | ≤ stage-1 rows, ≤ stage-1 cols | `ct_filtered()` | Tabs 3, 4 (overlap QC, deconvolution) | QC'd working matrix |
| 3 | `ref` / `active_reference()` | numeric matrix, beta scale | reference-specific CpG rows × 2–19 cell-type cols (registry) or data-dependent (custom) | `active_reference_full()`/`active_reference()` | `fs_result()`, `decon_result()` | Cell-type centroid reference |
| 4 | `rank_df` | data.frame | rows = `nrow(ref)`, 8 columns | `methyl_ct_marker_rank()` | `fs_result()`, `ct_active_marker_df()` | Per-CpG marker candidacy metrics |
| 5 | `fs_result()$selected` | data.frame | rows ≤ `nrow(rank_df)`, capped at `top_n` | `fs_result()` (optional) | `ct_active_markers()` | Chosen marker CpG set |
| 6 | `ct_active_markers()` | character vector | length = marker count (selected or full reference) | `ct_active_markers()` | `ct_overlap()`, `decon_result()` | The CpG ID set deconvolution will attempt to use |
| 7 | `ct_overlap()` | list/data.frame | scalar summary + per-type breakdown | `methyl_ct_overlap_qc/by_type()` | `ct_overlap_ok()`, `ct_refqc_ui` | ID-presence QC gate (not completeness-aware) |
| 8 | `ref_use` (inside `decon_result()`) | numeric matrix | rows = markers ∩ reference, cols = reference cell types | `decon_result()` | `methyl_ct_run_epidish/hepidish()` | Marker-restricted reference actually passed to EpiDISH |
| 9 | `decon_result()$fractions` | numeric matrix | rows = samples, cols = cell types | `methyl_ct_run_epidish/hepidish()` via `decon_result()` | Tabs 5, 6, 7; `results$celltype` | Estimated cell-type proportions |
| 10 | `results$celltype` | named list (scalars/small vectors) | fixed 5 fields | `observeEvent(decon_result(), ...)` | `build_mx_context()` (ArthOChat) | Session-level summary for the AI assistant's context |
| 11 | reconstructed matrix | numeric matrix | rows = common CpGs, cols = common samples | `methyl_ct_reconstruct()` | `val_result()` | Forward-model self-consistency check |
| 12 | `val_result()` | list | 4 overall scalars + per-sample data.frame | `methyl_ct_validation_metrics()` | Tab 6 outputs, export report | Validation summary |
| 13 | `cmpm_result()$fractions_by_method` | named list of numeric matrices | 2–3 matrices, each rows = samples × cols = cell types | `methyl_ct_compare_methods()` | Tab 6 comparison outputs | Cross-method agreement inputs |
| 14 | `cmp_result()$stats$table` | data.frame | rows = cell types, columns = test/statistic/p/effect/fdr | `methyl_ct_group_stats()` | Tab 5 comparison outputs, export | Phenotype-group statistical comparison |
