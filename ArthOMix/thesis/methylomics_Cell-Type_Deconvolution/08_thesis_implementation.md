# 08. Thesis Implementation Writeup — Methylomics Cell-Type Deconvolution

## 8.1 Academic paragraph

Bulk DNA methylation measurements reflect the aggregate epigenetic state of a heterogeneous mixture of cell types, and differences in cellular composition between biological groups are a well-recognized confounder of differential methylation analysis: a locus that appears differentially methylated between disease and control cohorts may in fact only be tracking a shift in immune-cell proportions rather than a true within-cell-type regulatory change. Reference-based deconvolution addresses this by modeling the observed bulk methylation profile as a constrained linear mixture of purified reference cell types' own methylation signatures, and solving for the mixing proportions. The Cell-Type Deconvolution submodule of the ArthOMix Methylomics pipeline implements this workflow end-to-end using the Bioconductor `EpiDISH` package, offering three estimation strategies — Houseman-style constrained projection (CP, via quadratic programming), robust partial correlations (RPC, via robust linear regression), and a CIBERSORT-adapted support-vector formulation (CBS) — together with EpiDISH's two-stage hierarchical method (`hepidish`) for resolving a tissue's immune-cell fraction into its own blood-cell subtypes using an independent second reference. Seven published reference panels spanning whole-blood (7-, 12-, and 19-cell-type resolutions) and epithelial-tissue compositions are provided out of the box, alongside support for a user-supplied custom reference. Rather than approximating methods for which no verified implementation is installed — MethylResolver, IDOL-optimized reference libraries, and true reference-free deconvolution — the module explicitly discloses their unavailability with a stated reason, a deliberate design choice that prioritizes scientific honesty over apparent feature completeness. Marker-CpG selection, reconstruction-based self-consistency validation, cross-method agreement analysis, and non-parametric group-comparison statistics with false-discovery-rate correction round out a pipeline that takes a quality-controlled beta-value matrix as its only required input and returns an estimated, publication-ready sample-by-cell-type composition table as its principal output.

## 8.2 Implementation description (XomicShiny-style)

**What was implemented:** A 7-tab Shiny submodule (Data & QC → CpG Feature Selection → Reference & Method → Deconvolution → Cell Composition → Validation → Export) that estimates cell-type proportions from a bulk DNA methylation beta-value matrix (CpG probes × samples), sourced either from the shared Methylomics Dataset tab or a module-scoped upload.

**Which functions/methods:** Standard probe/sample QC filters (`methyl_filter_missing()`, `methyl_filter_sex_chr()`, `methyl_filter_snp()`, `methyl_filter_cross_reactive()`, `methyl_filter_detection_p()`) narrow the working matrix; a purpose-built marker-ranking function (`methyl_ct_marker_rank()`) scores every reference CpG by an effect size and specificity computed directly off cell-type centroid values (no fabricated significance test, since the reference panels provide no per-sample replicates to test against); `EpiDISH::epidish()` (methods `CP`/`RPC`/`CBS`) and `EpiDISH::hepidish()` perform the actual constrained-projection, robust-regression, and support-vector-regression estimation, verified deterministic and correctly non-negative/sum-to-one by direct inspection of the installed package's internal solver code; `stats::wilcox.test()`/`stats::kruskal.test()` with Benjamini-Hochberg correction (`methyl_ct_group_stats()`) test estimated fractions against an uploaded phenotype grouping; a forward mixture-model reconstruction (`methyl_ct_reconstruct()`, `methyl_ct_validation_metrics()`) validates internal self-consistency via correlation, RMSE, MAE, and R².

**What they accomplish:** The pipeline converts a raw or partially-processed methylation matrix into a QC-filtered working matrix, an evidence-based marker CpG panel, and finally a samples-by-cell-types fraction matrix, alongside composition visualizations (stacked bar, heatmap, PCA/MDS, correlation matrix), group-difference statistics, reconstruction diagnostics, and a cross-method agreement comparison — all downloadable, with a per-figure PNG export and a full-session text summary report.

**Why important:** Cell-type composition is both a required confounder-adjustment covariate for any downstream differential-methylation or region-based analysis on heterogeneous tissue, and a biologically meaningful readout of immune or tissue-composition shifts in its own right. By restricting itself to a verified, installed estimation backend and disclosing every unimplemented method rather than approximating it, the module produces results a user can trust as an accurate description of what was actually computed, not an aspirational description of a fuller pipeline.

## 8.3 Methods-section-ready version (2–4 sentences)

The Cell-Type Deconvolution module comprises seven sequential tabs — data QC, marker-CpG feature selection, reference/method selection, deconvolution, composition visualization, validation, and export — operating on a quality-controlled DNA methylation beta-value matrix (CpG probes × samples) as its core input. Cell-type proportions are estimated using the `EpiDISH` R package's Houseman-style constrained projection (CP), robust partial correlations (RPC), CIBERSORT-adapted support-vector regression (CBS), and two-stage hierarchical (`hepidish`) methods against one of seven published reference panels or a user-supplied custom reference, producing a samples-by-cell-types fraction matrix as the principal output. This output is validated by reconstructing the observed methylation from the fitted mixture model and by cross-comparing methods on identical inputs, and is used to test for cell-composition differences between phenotype groups and to support confounder-aware interpretation of downstream differential methylation results.
