# 2.BB Sex-Stratified Differentially Methylated Region Analysis

## 2.BB.1 Rationale

Single-CpG testing (Section 2.AA) established that the female stratum carries genuine, calibrated genome-wide-significant signal (eighteen CpGs at bacon-corrected FDR < 0.05), while the male stratum, at n=196, retained none at the same threshold despite the underlying model being properly calibrated (Section 2.AA.8). This does not imply the male stratum carries no usable signal; it implies that whatever signal is present is not concentrated enough at any single CpG to survive a 412,492-test genome-wide correction on its own. Differentially methylated region (DMR) analysis addresses this directly: it aggregates spatially adjacent, correlated CpGs into a single region-level statistic, using a Gaussian-kernel-smoothed extension of the underlying per-CpG test statistics (Peters et al., 2015; Peters et al., 2021). This both reduces the effective number of independent tests relative to testing every CpG individually, and increases power specifically when a true effect is distributed across several neighbouring CpGs rather than concentrated at one, a pattern consistent with the diffuse, low-magnitude signal already characterised for this cohort (Section 2.Z.5). A region-level result is additionally the more natural unit for the Mendelian randomisation and colocalisation stage this chapter works towards, since published methylation quantitative trait locus (mQTL) resources characterise genetic influence on methylation across local, multi-CpG regions rather than at single, isolated probes, and DMRs are conventionally annotated directly to an overlapping gene (Section 2.AA.8).

## 2.BB.2 Constructing the per-CpG input object

DMRcate's `DMRcate::dmrcate()` function operates on a `CpGannotated-class` object: a `GRanges` object carrying, per CpG, a test statistic, an uncorrected p-value, an effect size, and an individual-CpG FDR (Peters et al., 2021). The standard route to this object, `DMRcate::cpg.annotate()`, fits its own internal linear model directly from a beta/M-value matrix and design formula. That route was not used here; instead, the `CpGannotated` object was constructed directly, using the surrogate-variable-adjusted, bacon-corrected per-CpG statistics already produced for each sex stratum (Section 2.AA.4), together with each CpG's chromosome and base-pair position from `ChAMPdata::probe.features`. This ensures the region-level test operates on the calibrated statistics established as necessary for this cohort, rather than on an unadjusted refit that would reintroduce the residual genomic inflation Section 2.AA was built to resolve.

The object's `is.sig` field, which determines which CpGs seed a candidate region, was set from the nominal (uncorrected-for-genome-wide-testing) bacon-corrected p-value, p < 0.05, rather than from the genome-wide FDR used to define the panels in Section 2.AA.5-2.AA.6. This is a documented DMRcate tuning parameter, not an ad hoc relaxation: the package's own documentation for this threshold notes it as "the primary thresholding parameter for calling DMRs," and the object's `ind.fdr` field separately retains the true, unmodified genome-wide FDR from Section 2.AA.4 throughout, so the object remains internally accurate about both quantities. Using genome-wide FDR<0.05 as the seeding threshold would have returned zero candidate CpGs, and therefore zero DMRs, in the male stratum, defeating the purpose of moving to a region-level test for the stratum it is most intended to help. At the nominal p<0.05 threshold used, the resulting seed rate was close to the 5% expected under a correctly calibrated null in both strata (8.0% female, 5.6% male; Section 2.AA.8), indicating that seeding itself was not, at this stage, dominated by residual inflation.

## 2.BB.3 DMR calling

Regions were called independently per stratum with `DMRcate::dmrcate()`, using a Gaussian kernel bandwidth of 1000 nucleotides and a bandwidth-scaling factor of 2, the package's own stated recommendation for Illumina array data (half a kilobase of genomic distance corresponding to one standard deviation of kernel support; Peters et al., 2021). Candidate regions were converted to genomic ranges with `DMRcate::extractRanges()`, referenced to the hg19 genome build, consistent with the build underlying the `ChAMPdata` probe annotation used throughout this chapter (Section 2.X.2), which additionally annotates each region with any directly overlapping gene.

## 2.BB.4 Region-level significance

DMRcate reports several combined-probability statistics per candidate region, including a Stouffer transform of the constituent CpGs' individual FDR-corrected p-values (Peters et al., 2021). Because this Stouffer statistic is not itself corrected for the number of candidate regions tested in a stratum, an explicit Benjamini-Hochberg correction was additionally applied across all candidate regions' Stouffer values within each stratum, treating each region as one test; this region-level FDR is referred to below as the region-level correction, to distinguish it from the individual-CpG FDR already embedded in DMRcate's own statistic.

Two figure types were produced per stratum, at the fixed canvas size used throughout this chapter (`FIG`, `config/config.R`: 2400 x 1800 px, 300 dpi), with no in-plot titles: a region-level volcano plot (mean Δbeta across each region's constituent CpGs against -log10 region-level FDR, region-level-significant regions highlighted), in the same visual format as the single-CpG volcano plots of Section 2.AA, but with the region rather than the CpG as the plotted unit; and a region-level Manhattan-style plot (genomic position, ordered by chromosome, against -log10 region-level FDR).

## 2.BB.5 Sex-stratified biomarker candidate panel

A final candidate panel was constructed per sex, combining two evidence tiers rather than pooling them into one undifferentiated list. The first tier consists of each stratum's genome-wide FDR-significant single CpGs from Section 2.AA.5 (eighteen in females, none in males). The second tier consists of the CpGs constituting the fifty most significant candidate regions per stratum by the region-level correction (Section 2.BB.4), rather than the full set of regions passing that correction. A top-fixed-count cut was used in preference to a blanket significance threshold because, as detailed in Section 2.BB.6, the great majority of candidate regions in both strata fall below conventional significance under the region-level correction, a result too large to serve as a focused candidate panel and, in aggregate, not sharply separable into "significant" and "non-significant" tiers by threshold alone; a top-50 cut is reported as an explicit, stated compromise on panel size rather than as a claim that regions beyond that rank are false.

## 2.BB.6 Results

**Candidate regions and seeding.** DMR calling on the surrogate-variable-adjusted statistics identified 4,657 candidate regions in the female stratum and 3,414 in the male stratum, seeded from 32,987 (8.0%) and 23,179 (5.6%) nominally significant CpGs respectively (Table 2.BB.1).

**Table 2.BB.1.** Candidate and significant DMR counts by sex.

| Stratum | Seed CpGs (nominal p<0.05) | Candidate DMRs | Stouffer<0.05 | Region-level FDR<0.05 |
|---|---|---|---|---|
| Female | 32,987 (8.0%) | 4,657 | 3,932 | 3,792 |
| Male | 23,179 (5.6%) | 3,414 | 2,550 | 2,182 |

Applying the region-level Benjamini-Hochberg correction (Section 2.BB.4) in addition to DMRcate's own Stouffer statistic changed the significant count only modestly in both strata (3,932 to 3,792 in females; 2,550 to 2,182 in males), because the underlying distribution of candidate-region p-values was itself shifted well below the value expected under a null distribution across most of its range (median Stouffer p-value 0.011 in females, 0.022 in males, against a null expectation of approximately 0.5), rather than concentrated in a small tail of strongly significant regions against an otherwise flat background.

**Diagnostic checks.** Three checks were carried out to assess whether this elevated rate reflects residual technical inflation, as it did in an earlier attempt at this analysis built on unadjusted statistics (a run whose implausible yield, discussed in Section 2.AA.8, was not adopted), or genuine biological signal.

First, the extended MHC region (chromosome 6, 25-35 Mb) was tested as a candidate explanation, since it is both a region of exceptionally high linkage disequilibrium and probe density and the single most robustly replicated genetic and epigenetic risk locus in rheumatoid arthritis (Liu et al., 2013). MHC CpGs did not disproportionately drive the elevated seed rate: the nominal seeding rate within the MHC region (9.3% female, 6.1% male) was only marginally higher than outside it (8.0% female, 5.6% male), and MHC CpGs, 2.9% of the array, contributed only 3.2-3.4% of all seed CpGs genome-wide. The elevated rate is therefore genuinely distributed across the genome rather than attributable to this one structurally unusual locus.

Second, despite this, the single most significant region in both strata independently localised to the MHC. The female stratum's top region (chr6:32,551,749-32,552,453, Stouffer p = 3.8x10^-10, region-level FDR = 1.8x10^-6) directly overlaps *HLA-DRB1*; the male stratum's top region (chr6:32,847,527-32,847,845, Stouffer p = 2.8x10^-9, region-level FDR = 9.4x10^-6) lies within the same extended MHC locus. *HLA-DRB1* is the original and most extensively replicated genetic risk locus for rheumatoid arthritis, and Liu et al. (2013), the source of this chapter's dataset, report the MHC region as their own principal finding. Independently recovering it as the top-ranked result in both sexes is a substantive external validity check on this analysis.

Third, the two strata's significant region lists were tested for convergence. Of 3,857 genes overlapping a significant female region and 2,519 overlapping a significant male region, 744 were shared between the two sexes, against 471 expected under independence (hypergeometric test using the 20,621-gene array annotation as the background universe, p = 1.6x10^-45). This degree of overlap is far beyond chance and indicates the two independently fitted sex-stratified models are substantially converging on the same underlying loci. Direct physical overlap between the significant regions themselves was more modest (10.1% of female significant regions physically overlap a male significant region), consistent with shared genes carrying distinct, sex-specific differentially methylated sub-regions rather than identical regions in both sexes.

Taken together, these checks support the elevated region-level yield as reflecting a substantial component of genuine, cross-sex-convergent, biologically plausible signal, but they do not fully exclude some remaining contribution from residual technical or array-structural effects not captured by the covariates and surrogate variables already applied (Section 2.AA); this result is accordingly reported as a material improvement over, and a more credible basis than, the unadjusted attempt superseded by this analysis, rather than as a fully resolved one.

**Sex-stratified biomarker candidate panel.** Combining each stratum's genome-wide-significant single CpGs with the CpGs constituting its top 50 regions by region-level correction (Section 2.BB.5) yielded a female panel of 810 CpGs (17 from single-CpG significance only, 792 from the top-50 regions only, and 1 CpG supported by both lines of evidence) and a male panel of 724 CpGs, entirely region-supported, since no CpG in the male stratum reached single-CpG genome-wide significance. These two panels constitute the sex-stratified candidate CpG sets carried forward from the differential methylation stage of this chapter.
