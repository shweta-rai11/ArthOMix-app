# 2.CC Sex-Stratified Weighted Co-Methylation Network Analysis

## 2.CC.1 Rationale

The differential methylation stages of this chapter (Sections 2.Z, 2.AA, 2.BB) test each CpG, or each spatially adjacent cluster of CpGs, individually against RA status. Weighted correlation network analysis (WGCNA; Zhang & Horvath, 2005; Langfelder & Horvath, 2008) addresses a different question: rather than testing single features, it groups CpGs into modules on the basis of their pairwise correlation structure across samples, independently of disease status, and only then tests whether a module's summary profile (its eigengene, the first principal component of its constituent CpGs) associates with RA. This can recover coordinated signal distributed across many weakly-associated CpGs that co-vary as a unit, a pattern neither single-CpG nor spatially local region-based testing is designed to detect, and collapses the genome-wide multiple-testing burden to the number of modules found (of the order of tens to low hundreds) rather than hundreds of thousands of individual tests. The method, and the R/Bioconductor package implementing it, retain the name WGCNA irrespective of the data type analysed; it has been applied directly to Illumina DNA methylation array data under this same name in multiple published studies (e.g. Men et al., 2017).

## 2.CC.2 Input data: known-covariate residuals, not surrogate-variable-adjusted residuals

WGCNA requires a broad, correlation-structure-rich set of features to discover genuine co-methylation modules; it was not run on the DMP or DMR biomarker panels (Section 2.BB.5), which are small, already RA-significance-filtered CpG lists both statistically inadequate for module discovery and circular to test for RA-association a second time.

The input actually used required a substantive correction during this stage's development, which is documented here rather than silently omitted. An initial version of this analysis used the surrogate-variable-adjusted residual matrices already built for single-CpG testing in Section 2.AA.7 (age, smoking, cell-type composition, and 83/40 surrogate variables regressed out). That version produced an implausibly high fraction of CpGs assigned to no module at all (81.3% in females, 70.8% in males, well above typical published WGCNA analyses) and zero real, non-grey modules reaching genome-wide significance for RA status in either sex. Investigating this against the literature identified the specific cause: Cote, Young & Huckins (2022), directly comparing confound-adjustment strategies for gene co-expression network construction, found that latent-factor methods such as PEER (the same general category of method as SVA, both estimating and removing hidden axes of variation) produce markedly sparser, more poorly connected networks than known-covariate-only adjustment, because "hidden factors likely represent biological co-expression patterns," so removing them removes real, shared signal along with technical noise. Surrogate-variable methods are designed to improve sensitivity for single-feature differential testing (their appropriate and necessary use in Sections 2.AA-2.BB of this chapter), not to preserve the correlation structure a network method depends on. Cote et al. (2022) recommend known-covariate adjustment, without latent-factor correction, as the more suitable input for co-expression network construction specifically.

Following that recommendation, this script builds its own residual matrix directly, independently of Section 2.AA.7's output: for each sex stratum, all 412,492 QC-passed probes were first residualized against age, smoking status, and the cell-type covariates only, fitted with `limma::lmFit()`, with `group` (RA/Control) excluded from the regression, exactly as in the null-model logic already established in Section 2.AA.3, so that RA-associated variation remains in the residuals for the module-trait correlation step (Section 2.CC.4) to detect.

A full-probe-set (412,492 CpGs, unfiltered) network was attempted directly on these residuals but found computationally intractable on the available hardware: `blockwiseModules()` processing the full set in sequential blocks exceeded available RAM. The network is therefore built on the top 20,000 most variable probes, selected by median absolute deviation (MAD) computed on the residuals themselves, not on the raw M-values. This differs in two respects from the 20,000-top-variable-probe convention used for surrogate-variable estimation elsewhere in this chapter (Section 2.AA.3), and from an earlier version of this stage's own input, both of which selected on raw M-value variance before adjustment: selecting on post-adjustment residual variability targets CpGs that remain variable for reasons other than the already-removed known confounds, rather than CpGs whose raw variance may itself be substantially attributable to those confounds; and MAD, using absolute rather than squared deviations, is less sensitive than variance to a small number of extreme single-sample values. WGCNA applied to Illumina methylation array data with a comparably-sized top-variable-CpG input (top 5% by variability after a detectability filter, ~19,786 sites) has precedent in Men et al. (2017).

## 2.CC.3 Network construction and module detection

For each sex stratum independently, `WGCNA::goodSamplesGenes()` confirmed no probes or samples required removal for excessive missingness. The soft-thresholding power was selected with `WGCNA::pickSoftThreshold()`, testing powers 1-10 and even powers 12-20, using a signed network (`networkType = "signed"`); signed (or signed hybrid) networks are the WGCNA package authors' documented recommendation over unsigned networks, because an unsigned network combines positively- and negatively-correlated CpGs into the same connectivity measure, which for methylation data would merge hyper- and hypomethylated CpGs moving in opposite directions into a single module.

Power selection itself departs from `pickSoftThreshold()`'s own automatic mechanism. In an earlier run on this same 20,000-probe input, neither stratum reached the function's default target (scale-free topology fit R² ≥ 0.85) at any tested power (best observed: 0.756 female, 0.673 male, both at the top of the tested range, power 20); a lower target of 0.80 had separately been tried and rejected earlier in this stage's development, on a differently-constructed 20,000-probe input, because it produced a far sparser, less informative network (grey fraction rose from 35.1% to 77.0%, RA-associated modules fell from 43 to 1) for only a marginal fit gain. Given neither the 0.85 nor a lowered 0.80 target was reachable or advisable, the power actually used for `blockwiseModules()` is computed directly from each stratum's own `pickSoftThreshold()` fit-index table as the single power, among those tested, with the highest observed SFT.R² (`fi$Power[which.max(fi$SFT.R.sq)]`) -- not a hardcoded value, and not the WGCNA-documented generic fallback power (14), which is a package-level default not derived from this dataset. In this run that resolved to power 20 in both strata, since 0.756 (female) and 0.673 (male) were each strictly the highest fit observed among all 15 tested powers. This is not a guarantee that scale-free fit would not continue improving beyond power 20; the tested range (1-10, even powers 12-20) was not extended to check, and this is a limitation of the power selection carried out here, stated plainly rather than implied.

Network construction, topological overlap matrix (TOM) calculation, and module detection were performed in one step with `WGCNA::blockwiseModules()` (signed network, signed TOM, minimum module size 20, module-merging cut height 0.25 -- the function's own default -- deepSplit = 2, all other arguments at package defaults; `maxBlockSize = 5000`, likewise the function's own default). `maxBlockSize` was reduced to this default from a larger, non-default 20,000 tried earlier in this stage's development, because a single 20,000 x 20,000 signed TOM (a several-gigabyte in-memory object) was found to exceed comfortably available RAM on the hardware available for this analysis. Because the 20,000-probe input (Section 2.CC.2) exceeds this block-size ceiling, `blockwiseModules()` first pre-clusters probes into blocks of at most 5,000 using a projective k-means procedure (the package's documented approach for inputs larger than `maxBlockSize`; Langfelder & Horvath, 2008), then constructs the signed network and computes the TOM separately within each of the resulting ~4 blocks per stratum, detects modules within each block by average-linkage hierarchical clustering with dynamic tree-cutting, and finally merges modules with highly correlated eigengenes (eigengene correlation > 0.75, i.e. mergeCutHeight = 0.25) across blocks into one module set per stratum. A resulting limitation is that two CpGs assigned to different blocks by the preclustering step can only end up in the same module if their respective block-level modules are subsequently merged on the basis of eigengene similarity, so final module composition is not entirely independent of the preclustering partition; this trade-off was accepted in exchange for making network construction computationally tractable (Section 2.CC.2). Each module's eigengene was correlated against RA status (coded 0 = Control, 1 = RA) with Pearson correlation, and the associated p-value obtained from `WGCNA::corPvalueStudent()`; p-values were Benjamini-Hochberg corrected across all real (non-grey) modules within each stratum. "Grey" is WGCNA's reserved label for CpGs not assigned to any module and was excluded from this correction and from all "module" counts and figures reported below, consistent with its function as a residual bucket rather than a co-methylation module. (Development note: an earlier version of the script computed the BH correction over all modules including grey, one more test than intended, before this was caught and corrected; the effect on the reported results below was negligible -- see Section 2.CC.5 footnote -- since it only ever added one extra, and typically non-competitive, test to the correction.)

A namespace conflict was encountered and resolved during this stage's development: loading `ChAMPdata` after `WGCNA` masks the `cor` symbol with a version lacking arguments (`weights.x`, `weights.y`, `cosine`) that `blockwiseModules()` requires internally, causing the function to fail after substantial computation time with the error "unused arguments." This is a documented WGCNA/Bioconductor package-loading conflict; explicitly rebinding `cor` to `WGCNA::cor` immediately after loading both packages is the standard resolution and was applied throughout.

## 2.CC.4 Enrichment of RA-associated modules for the DMP/DMR biomarker panel

For each stratum's real, genome-wide FDR-significant (FDR < 0.05) modules, a two-sided Fisher's exact test assessed whether that module's constituent CpGs were over-represented among the DMP/DMR biomarker panel (Section 2.BB.5) relative to the full probe background tested in this stage, with Benjamini-Hochberg correction applied across all tested modules within a stratum. This tests convergence between two independently derived lines of evidence (single-CpG/region significance versus network-based module membership); it is not a validation of one method by the other, and a lack of enrichment does not invalidate either result on its own; the two methods are structured to detect different kinds of pattern in the same data.

This general strategy -- deriving co-methylation modules and single-CpG/region differential-methylation results independently, then cross-referencing the two for convergent candidates -- has direct precedent in the DNA methylation biomarker literature. Wang et al. (2021), in a monozygotic-twin depression EWAS, ran WGCNA and an independent epigenome-wide/DMR analysis separately and reported that "common genes... and enrichment terms were identified in both methylation analysis and WGCNA" (e.g. BMP2, PRDM7, KCNIP1, GRIK2), using the overlap itself as convergent evidence for candidate biomarkers -- the same logic applied in this section and in the follow-on feature-selection work in script06_feature_selection. (A related but distinct variant, not used here, runs WGCNA directly on CpGs already restricted to significant DMRs rather than on an independently-selected broad probe set; see e.g. Hotta et al. (2018) for DMR-network construction on that basis.)

**Network construction.** Table 2.CC.1 summarises soft-thresholding power selection and module detection for each stratum. Neither stratum reached the target scale-free fit (SFT.R² ≥ 0.85) at any tested power (female maximum SFT.R² = 0.756, male maximum SFT.R² = 0.673, both at power 20); per Section 2.CC.3, the power actually used for `blockwiseModules()` was therefore the best-observed-fit power in each stratum's own `pickSoftThreshold()` output, which resolved to power 20 in both strata (not the WGCNA-documented signed-network fallback of 14).

An earlier run of this stage, on a differently-constructed 20,000-probe input (raw-variance selection before residualization, `mergeCutHeight = 0.15`, `maxBlockSize = 20000`; see script history), detected substantially more, smaller modules in both strata (104 female, 66 male). The module counts reported here are not directly comparable to that run: `mergeCutHeight = 0.25` (the package default used here, versus the earlier, non-default 0.15) merges modules whose eigengenes correlate above 0.75 rather than above 0.85, which alone would be expected to substantially reduce the final module count; the change in probe-selection order (post-residualization MAD versus pre-residualization variance) is a further, non-separable difference between the two runs. The lower module count here should therefore be read as a consequence of these methodological changes, not as evidence of a weaker or stronger underlying co-methylation signal relative to the earlier run.

**Module-trait correlation.** In the female stratum, 17 of 18 real modules reached genome-wide FDR < 0.05 for correlation with RA status; 15 were positively correlated (higher eigengene value associated with RA) and 2 negatively correlated (`brown`, 304 CpGs, r = -0.281, FDR = 2.1x10^-9; `yellow`, 215 CpGs, r = -0.178, FDR = 1.1x10^-4). The largest and most significant module was `turquoise` (8,030 CpGs, r = 0.302, FDR = 1.6x10^-10). The one real module not reaching FDR < 0.05 was `grey60` (25 CpGs, r = -0.022, FDR = 0.62).

In the male stratum, no real module reached genome-wide FDR < 0.05 for correlation with RA status, consistent with the statistical power limitation characterising the male stratum throughout this chapter (n = 196). The male suggestive tier (nominal p < 0.05, not genome-wide significant; Section 2.CC.3) contained 14 of the 36 real modules tested -- descriptively well above the ~1.8 modules (36 x 0.05) that would be expected under a uniform null by chance alone, though this comparison is illustrative rather than a formal test, and none of the 14 survived multiple-testing correction (FDR range 0.072-0.121). The strongest were `green` (101 CpGs, r = 0.218, p = 2.2x10^-3, FDR = 0.072) and `turquoise` (8,632 CpGs, r = 0.205, p = 4.0x10^-3, FDR = 0.072).

> *Footnote, BH-correction fix (caught during review):* the FDR values above were recomputed after fixing a code/documentation mismatch -- the Benjamini-Hochberg correction had been running over all modules including `grey` (one extra, non-real test), rather than over real modules only as Section 2.CC.3 already documented it should be. The fix changed individual FDR values only marginally (e.g. female `turquoise` 1.7x10^-10 -> 1.6x10^-10; male best case `green`/`turquoise` 0.074/0.074 -> 0.072/0.072) and changed no significance call reported in this document: the female 17-of-18 and male 0-of-36 counts are identical before and after the fix.

**Enrichment against the DMP/DMR biomarker panel.** The 17 female FDR<0.05 modules were tested for enrichment of the female DMP/DMR biomarker panel (810 CpGs; Section 2.BB.5) against the 20,000-probe network background used in this stage. Only 67 of the 810 panel CpGs are present in that background -- the remaining 743 fall outside the top-20,000 MAD-selected probe set (Section 2.CC.2) and could not be assessed by this test. No module reached FDR < 0.05 in either direction: `turquoise` (8,030 CpGs) contained 20/67 panel CpGs (odds ratio = 0.633, raw p = 0.104, FDR = 1), `blue` (1,341 CpGs) contained 6/67 (odds ratio = 1.37, raw p = 0.457, FDR = 1), and the remaining 15 tested modules contained zero panel CpGs each (odds ratio = 0, FDR = 1, uninformative given the zero count). No male modules were tested, since no male module reached the FDR<0.05 threshold required to be a candidate for this test. Unlike an earlier run of this stage (superseded, see script history), which found a genome-wide-significant depletion of the panel within `blue`, this run finds no significant enrichment or depletion in either direction: the RA-associated co-methylation modules identified here and the DMP/DMR-derived biomarker panel neither confirm nor significantly diverge from one another in this analysis, reinforcing (Section 2.CC.4) that module-based and single-CpG/region-based testing are characterising substantially non-overlapping, and here statistically inconclusive-with-respect-to-each-other, aspects of the female-stratum signal.

## 2.CC.6 Post-hoc module consolidation (methods)

Section 2.CC.3's `blockwiseModules()` module count (18 real female modules, 36 real male modules) is the network's own natural resolution at the package-default merge setting (`mergeCutHeight = 0.25`, eigengenes merged above r = 0.75). On request, an additional, coarser, post-hoc consolidation of that same result was produced for interpretability, targeting at most `TARGET_MODULES = 10` real modules per stratum. This was originally implemented in a separate script, `05b_module_consolidation.R`, run after `05_wgcna_sexstratified.R` and reusing that script's saved network output (`wgcna_sexstratified.rds`) rather than reconstructing the network; it has since been folded into `05_wgcna_sexstratified.R` itself (Section 3c), reusing the residuals and module colors already held in memory from Section 3 instead of reloading/rebuilding them. In both versions, `WGCNA::mergeCloseModules()` re-clusters and re-merges module eigengenes directly from the already-computed module colors and expression matrix, which is computationally cheap and in particular does not require recomputing the topological overlap matrix (TOM) or repeating `blockwiseModules()`'s network construction -- the step that made the original run computationally expensive (Section 2.CC.3).

Because `mergeCloseModules()` takes a single `cutHeight` (the eigengene-dissimilarity threshold below which modules are merged) rather than a target module count directly, the target was reached by search: `cutHeight` was tried over `seq(0.25, 0.90, by = 0.05)` in ascending order (i.e., proceeding from the least to the most aggressive merge), stopping at the first value producing at most 10 real (non-grey) modules. Because this is a coarse step search rather than a continuous optimisation, the achieved module count can undershoot the target rather than land on it exactly -- the `cutHeight` step immediately before the stopping point may still exceed 10 modules, and the step at which it stops may already be well under 10; both occurred in this run (Section 2.CC.7). Module-eigengene-versus-RA-status correlation, its p-value, and Benjamini-Hochberg correction restricted to real modules were then recomputed exactly as in Section 2.CC.3, on the consolidated module set.

This consolidation is a supplementary, coarser view of the same network, not a replacement for the finer-grained result in Section 2.CC.5: both are retained (`*_merged10` output filenames for the consolidated version) so the choice of which to report is not made irreversibly at this stage. A reduction in module count that is not accompanied by a proportional loss of real signal will tend to increase the number of modules reaching FDR < 0.05, purely because Benjamini-Hochberg's correction denominator (the number of real modules tested) shrinks -- this is a mechanical consequence of testing fewer hypotheses, not evidence of a stronger underlying biological effect, and is called out explicitly where it occurs (Section 2.CC.7).

## 2.CC.7 Results (post-hoc module consolidation)

**Table 2.CC.2.** Post-hoc module consolidation summary, by sex.

| Stratum | Real modules before (Section 2.CC.5) | `cutHeight` used | Real modules after | FDR<0.05 modules after |
|---|---|---|---|---|
| Female | 18 | 0.40 | 7 | 6 |
| Male | 36 | 0.65 | 8 | 2 |

Neither stratum landed exactly on the 10-module target (Section 2.CC.6): female consolidation stayed at 18 modules through `cutHeight` 0.25-0.30, dropped to 14 at 0.35, then to 7 at 0.40 -- the search stopped there, as 7 is already at or under target, with no intermediate step tested between 14 and 7. Male consolidation declined more gradually (36, 36, 34, 34, 32, 28, 20, 11 across `cutHeight` 0.25-0.60) before reaching 8 at `cutHeight` 0.65, the step at which the search stopped.

**Female (7 real modules).** Six of seven reached FDR < 0.05: `black` (8,447 CpGs, r = 0.301, FDR = 6.5x10^-11), `brown` (304 CpGs, r = -0.281, FDR = 8.3x10^-10), `tan` (32 CpGs, r = 0.271, FDR = 2.2x10^-9), `yellow` (215 CpGs, r = -0.178, FDR = 1.2x10^-4), `blue` (1,341 CpGs, r = 0.123, FDR = 9.1x10^-3), and `lightgreen` (24 CpGs, r = 0.106, FDR = 0.022). `grey60` (25 CpGs, r = -0.022, FDR = 0.62) did not reach significance. Cross-referencing CpG membership against the Section 2.CC.5 18-module result confirms this is a direct coarsening of it, not an independent result: `brown`, `tan`, `yellow`, `blue`, `lightgreen`, and `grey60` here have exactly the same CpGs as their same-named counterparts in the 18-module result (unmerged at `cutHeight` 0.40); the new `black` module is exactly the union of the twelve remaining, all-positively-correlated 18-module-result modules (`turquoise`, 8,030 CpGs, plus `green`, `red`, the 18-module result's own separate 47-CpG `black`, `pink`, `magenta`, `purple`, `greenyellow`, `salmon`, `cyan`, `midnightblue`, and `lightcyan`), which merge into a single 8,447-CpG module at this `cutHeight`.

**Male (8 real modules).** Two of eight reached FDR < 0.05 -- a change from **zero** significant real modules in the Section 2.CC.5 36-module result: `cyan` (9,776 CpGs, r = 0.207, p = 3.6x10^-3, FDR = 0.029) and `blue` (4,332 CpGs, r = -0.178, p = 0.012, FDR = 0.049). The remaining six modules did not reach significance (FDR 0.20-0.66). `blue`'s FDR (0.049) sits close to the 0.05 boundary, and per Section 2.CC.6 the drop from 36 to 8 tested hypotheses is itself sufficient to move a module across the FDR<0.05 line without any change in the underlying correlation strength. Cross-referencing CpG membership confirms this mechanism directly: `blue` here has exactly the same 4,332 CpGs, and the same r = -0.178, as the Section 2.CC.5 `blue` -- it was not merged with anything at this `cutHeight`, and its correlation is completely unchanged; only the correction denominator (8 real modules tested here, versus 36 there) changed, moving its FDR from 0.098 (Section 2.CC.5) to 0.049 here. `cyan` is the union of `turquoise` (8,632 CpGs, r = 0.205, the Section 2.CC.5 module closest in correlation) with 28 further, smaller Section 2.CC.5 modules of both signs (all merging together at this `cutHeight` because their eigengenes had become close enough to each other, not because they all individually correlate with RA). This result should therefore be read as "detectable once the multiple-testing burden of the finer partition is removed by consolidating to fewer, larger modules," not as a stronger or newly-discovered male RA signal.
